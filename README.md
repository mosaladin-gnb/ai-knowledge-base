# AI Knowledge Base

A seven-chapter guide to how AI got here and how to use it well in education. It follows the story from the first question ("Can machines think?") to today's chatbots, and ends with practical guidance for the classroom.

**Read it online:** [[https://mosaladin-gnb.github.io/ai-knowledge-base/]]

## What is inside

The guide is built in layers: a **timeline**, split into **chapters**, each made of **sections** with **explainers** for key terms, and cited **sources** at the end of every chapter. A glossary on the home page links each term back to where it first appears.

There is also a page of [Simplified ideas](simplified-ideas.html): six big ideas, each drawn in a few pictures you can step through one at a time.

Every page has a light and dark appearance, and chapters have a **Surface** layer (the essentials) and a **Deep** layer (more detail).

## Run it on your own computer

Download or clone the repository and open `index.html` in a browser. Nothing needs to be installed. Each page is one self-contained file with its images included. The fonts load from Google Fonts, so without an internet connection the pages fall back to the system fonts.

## A note on dates

Chapters 6 and 7 are dated snapshots (26 October 2026). Prices, rankings, rules and tools change quickly, so check the sources listed in each chapter before relying on a figure.
